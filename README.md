# Topic Management System

A Laravel-based web application for managing topics and categories with features like CRUD operations, file uploads, search, filtering, and role-based access control.

## Features
- **Topic Management**: Create, update, delete, and list topics.
- **Category Association**: Assign topics to categories with relational database support.
- **File Uploads**: Securely upload and manage topic images.
- **Search & Filtering**: Easily search and filter topics.
- **Role-Based Access Control**: Separate admin and public user access.
- **Background Jobs**: Handle asynchronous tasks using Laravel queues.
- **Responsive Design**: Mobile-friendly views using Blade and Bootstrap.

## Tools & Technology
- **Framework**: Laravel
- **Languages**: PHP, JavaScript
- **Database**: MySQL
- **Frontend**: Blade, HTML, CSS, Bootstrap
- **Version Control**: Git, GitHub
- **Environment**: XAMPP, `.env` configuration
